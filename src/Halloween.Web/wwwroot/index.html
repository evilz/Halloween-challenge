LES RÈGLES DU LABYRINTHE

Du code à la survie.

Compatible avec le protocole REST du challenge vpTech 2020.

01

Le tour de jeu

Tous les bots vivants reçoivent leur observation en parallèle. Ils ont 3 secondes pour répondre.

  1. Déplacements simultanés des bots.
  2. Collisions et contacts avec les ennemis.
  3. Tirs simultanés, puis déplacement des spectres.
  4. Apparitions des ennemis et calcul du score.

Deux bots sur une même case meurent. Les tirs réciproques peuvent éliminer les deux tireurs.

02

Voir, tirer, revenir

Un bot reçoit uniquement les cases de son carré de vision. Les coordonnées commencent à (0, 0), en haut à gauche.

Un tir va en ligne droite, s'arrête au premier mur ou à la première cible et reste dans la zone visible. La recharge est réglable.

Un spectre neutre se capture au contact ; un spectre hostile tue. Après sa mort, un bot revient à la même case, dès qu'elle est libre.

03

Le contrat HTTP

POST /name, sans corps :

{ "name": "Mon bot", "email": "moi@example.com" }

POST /move, réponse :

{ "move": "up" }

Commandes : up, down, left, right et leur variante fire-. null permet d'attendre.

Timeout, erreur HTTP ou commande invalide : le bot reste immobile. Le journal indique le problème.
